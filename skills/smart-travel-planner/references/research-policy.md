# Research policy
Use native web search first where available; MCP search is a fallback. Start with destination overview, season/climate, transport, lodging areas, 4–8 candidate sights, major closures/holidays, fare/ticket policy, free options, and common practical risks. Cap first-pass queries at 10–20 and second-pass queries to unresolved profile decisions. Open primary sources for dynamic facts. Avoid scraping sites that block access. Label each datum current/forecast/historical/estimated. Open-Meteo supports weather/geocoding; forecasts are not useful far into the future. Free public endpoints can impose terms/rate limits; respect their attribution and usage rules.
