# Smart Travel MCP

Local stdio MCP server implemented against JSON-RPC tools protocol using Python standard library. Prefer `python <plugin-root>/installer/start_mcp.py` from any cwd; connect a compatible MCP host over stdin/stdout. It has no shell, credential, or system mutation tool. The only tool write is the explicitly invoked `download_image`, which validates image provenance and stays within `STP_IMAGE_DIR` (default plugin `outputs/images/`). Standard delivery supplies a controlled user workspace directory through the internal image pipeline. Provider coverage is described by `health_check`.

V1.0.1 Commons image metadata includes dimensions, cleaned descriptions and authors. An exact `File:` title found through host research is re-queried through the same Commons interface. Caller input cannot replace licenses or authorize arbitrary image URLs. Download checks MIME, size, signatures, pixel limits and, when Pillow is present, full decode. The pipeline adds identity/attraction binding, hashes and aspect-preserving DOCX captions with sources, license links and transformation notes. TLS errors remain failures, never justification to disable verification.

Provider adapters live in `src/providers/`: SearchProvider (host injection/optional Brave/explicit Wikipedia background), PlacesProvider and PlaceDetailsProvider (normalized OpenStreetMap Overpass mappings), TransitProvider (explicit unavailable default), geocoding (Open-Meteo + Nominatim fallback), weather, exchange, route (FOSSGIS OSRM), and registry/health. All outbound requests use `src/security/network.py`, including bounded body reads and redirect validation. OSM labels are not authoritative venue facts. Transit routing remains unavailable until a reliable provider is configured.

MCP calls return a stable envelope: `status`, `data`, `evidence`, `provider`, `checked_at`, `confidence`, and `limitations`. Search records retain title, URL/domain, snippet, retrieval/publication timestamps, source class, and confidence where provided. Host-native web search is primary; set `BRAVE_SEARCH_API_KEY` for the optional MCP web fallback. Without either, Wikipedia is degraded background only, never current travel evidence.
